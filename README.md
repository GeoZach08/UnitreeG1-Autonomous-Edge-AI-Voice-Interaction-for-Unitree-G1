# Project-Babis-Autonomous-Edge-AI-Voice-Interaction-for-Unitree-G1
A fully autonomous, 100% on-board AI interaction system for the Unitree G1 robot, specialized in Greek language NLP. Integrates YOLOv8, Gemini 1.5 Flash, and real-time Greek STT/TTS natively on the Jetson Orin, featuring custom PulseAudio routing and hardware FSM.
